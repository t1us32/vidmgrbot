# TikTok-консолидатор для Telegram

Когда в группе человек присылает ссылку TikTok, а бот-загрузчик (USaver) отвечает превью,
бот публикует одно сообщение «👤 Имя + 🔗 ссылка» и удаляет оба исходных.

## Как работает

1. Человек пишет **только** ссылку TikTok.
2. Загрузчик отвечает на неё (reply).
3. Бот сначала публикует новое сообщение, затем удаляет ответ загрузчика и исходную ссылку.

Если новое сообщение не отправилось, исходные не трогаются.

## Защиты, чтобы бот не снёс группу

| Защита | Что делает |
|---|---|
| Разрешённые чаты | Работает только в `ALLOWED_CHAT_IDS`, в остальных игнорирует всё |
| Разрешённые загрузчики | Реагирует только на сообщения ботов из `COMPANION_BOT_IDS`, по ID, а не по имени |
| Только человеческая ссылка | Удаляет только сообщения людей, ссылки от ботов не трогает |
| Только чистая ссылка | Сообщения с посторонним текстом не трогает, чтобы не потерять слова |
| Строгий хост | Проверка по hostname: `tiktok.com.evil.com` не пройдёт |
| Точечное удаление | Удаляет ровно два известных `message_id`, никаких диапазонов |
| Порядок | Сначала публикация, потом удаление |
| Защита от петли | Игнорирует собственные сообщения (в них тоже есть ссылка) |
| Защита от повтора | Одна ссылка обрабатывается один раз |
| Лимиты | Не больше 10 замен в минуту и 60 в час |
| Автопауза | Превышение часового лимита или 3 ошибки подряд останавливают бота и пишут админам |
| Предполётные проверки | Без права удаления или без выключенного privacy mode бот не стартует |
| Пропуск старого | Не обрабатывает очередь после перезапуска |
| DRY_RUN | По умолчанию только пишет в лог, без удалений |
| Журнал | Все действия пишутся в `actions.log` |

## Установка

### 1. BotFather
- `/newbot`, получить токен.
- `/setprivacy` → выбрать бота → **Disable**. Без этого бот не увидит сообщения загрузчика.

### 2. Группа
- Добавить бота в группу и дать права администратора с правом **удалять сообщения**.
- Если меняли privacy mode, удалите бота из группы и добавьте заново.

### 3. Запуск

```bash
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Заполните `.env`: `BOT_TOKEN`, `ALLOWED_CHAT_IDS`, `ADMIN_IDS`. `COMPANION_BOT_IDS` пока оставьте пустым, он нужен только после шага 4.

Тесты логики (без сети):

```bash
python -m unittest test_rules -v
```

### 4. Узнать ID
- ID группы: напишите в группе `/chatid` (от админа), бот ответит.
- ID загрузчика: пока `DRY_RUN=1`, отправьте ссылку TikTok в группу. В `actions.log` появится строка «Сообщение от бота id=...». Этот ID добавьте в `COMPANION_BOT_IDS`.

Заполнив `COMPANION_BOT_IDS`, проверьте:

```bash
python bot.py
```

В логе должно быть `[DRY_RUN] заменил бы сообщения ...`.

### 5. Боевой режим
Переключите `DRY_RUN=0` и перезапустите бота.

## Управление (только для ADMIN_IDS)
- `/status` — состояние и режим
- `/pause` — остановить замены
- `/resume` — возобновить после паузы (в том числе после автопаузы)
- `/chatid` — chat_id текущей группы

## Ограничения
- Telegram не даёт боту удалять сообщения старше 48 часов.
- Бот срабатывает, только если загрузчик отвечает **reply** на ссылку. По скриншоту так и сделано. Если загрузчик отвечает без reply, логика не сработает.
- Превью TikTok в итоговом сообщении отключено (`LinkPreviewOptions(is_disabled=True)` в `bot.py`), чтобы не плодить карточки.
